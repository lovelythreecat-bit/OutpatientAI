# 在线咨询交互原型

基于 2026-10-22 的需求设计，提供四个可切换的主要画面及入库成功页。直接打开 `index.html` 即可体验，不依赖接口、模型、数据库或外部资源。

## 体验路径

1. 顶部选择“AI 转人工”，在对话底部点击“转人工咨询”。
2. 在下拉框选定医生；选项包含姓名、科室和职称。选定后自动进入长期聊天并出现摘要，无第二次发送确认。
3. 顶部选择“医生聊天”，点击“选择内容”，勾选任意相关消息，点击“存入知识库”。
4. 在“确认知识内容”页直接编辑文章标题、正文。使用“确认存入知识库”体验处理中与完成反馈。
5. 顶部“患者聊天”可直接查看聊天布局；手机宽度使用聊天标题左侧返回按钮打开会话列表。

## 设计依据

- 延续项目 `client/src/styles/global.css` 的深青绿 `#197568`、暖白背景 `#f5f6f2`、浅绿选中状态和中文系统字体。
- 患者端继承现有 AI 问诊截图与门户导航结构。医生端对齐 `client/src/layouts/AdminLayout.vue`：240px 深绿左侧菜单、76px 顶部工具栏、右侧业务内容；侧栏收起后宽度为 76px。
- 医生咨询内容采用“患者会话列表 + 聊天”两栏；患者信息默认收起，点击聊天顶部“患者信息”展开。知识整理记录放在页面顶部；知识文章确认和完成页沿用同一医生端框架。
- 手机端对齐现有 `MobileNavigation.vue` 的顶部入口、底部常用功能与全部功能菜单。此原型仅咨询流程可交互，其他菜单标明沿用现有页面。
- UI/UX Pro Max 的医疗产品通用搜索最初返回营销页面与拟物风格，不适用于当前工作界面，未采纳或保存。收窄搜索后采用 `Accessible & Ethical` 结果的可读性、明确焦点与大点击区域建议。
- 项目采用 Vue 3；本次原型使用独立 HTML/CSS/JS，便于直接打开评审，不修改产品路由、安装组件库或接入业务接口。
- 无需医生理解文件格式。文章以正常标题、段落和列表呈现，提供直接编辑。后台生成 Markdown 与向量化是后续业务实现，不出现在医生操作文案中。

## 原型边界

所有人物、消息、AI 回答与处理结果都是虚构示例。发送、摘要整理、入库为本地演示，不写入任何业务系统。文章修改和演示消息仅在当前页面会话内保留，刷新后重置。生成文章遵循所选示例消息，实际大模型整理和隐私处理不在原型中实现。

重点覆盖正常主流程、空选择、整理中、入库中、成功反馈、搜索无结果、草稿返回以及手机布局。后端错误重试、数据库唯一性、真实已读同步和断线恢复以设计文档为准。
