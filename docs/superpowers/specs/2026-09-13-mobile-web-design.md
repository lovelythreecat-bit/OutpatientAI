# 移动 Web 全功能适配

目标：现有 PC 功能在手机浏览器可访问、可阅读、可操作，共用账号、权限、接口和网址。

采用 Vue 3 项目内的响应式方案，768px 以下启用移动布局。独立移动项目会复制 28 个页面的业务代码，增加功能不同步的风险；仅压缩 PC 样式无法解决表格及导航的触摸操作，因此采用共享业务、分别展示表格和卡片的方案。

患者覆盖首页及公告详情、AI 问诊及历史会话、症状推理及疾病详情、在线咨询、预约挂号、健康档案、健康资讯及详情、个人资料、头像与密码。医生覆盖工作台、回复咨询、预约状态操作、患者档案增删改、个人中心。管理员覆盖数据图表、用户、医生、科室、知识文件上传及删除、知识图谱、咨询、预约、文章、公告、个人中心。登录和注册同步适配。

移动壳使用标题栏、全部功能抽屉、常用底部导航；抽屉切换页面后关闭。列表复用现有列定义和操作插槽，在手机上显示带字段名称的完整卡片。保持原有搜索、分页、校验、错误反馈、确认删除逻辑。弹窗限制在视口内，表单标签在上，详情内容可换行，图表保留自适应缩放。

AI 历史列表在手机上可展开收起，发送区随动态视口调整；中文输入法确认不触发发送，发送中不切换会话。PC 保留原有布局。样式支持安全区及 320px 以上视口。

验证：组件行为测试覆盖卡片字段、插槽操作、空列表；构建验证所有页面；浏览器检查三角色导航、卡片、弹窗、搜索、分页及聊天。测试外部 API 使用明确标记的测试数据，不对真实业务数据执行写操作。真实后端不可用时明确记录联调边界。
